# Project 3


**Title:** Hospital Operational Efficiency Dashboard

**Tools Used:** SQL Server, SQL Server Integration Services (SSIS), Power BI, DAX

**Data Period:** January 2024 – December 2025

**Dataset:** Synthetic NHS-style hospital operational data

## Project Overview

This project examines hospital operational performance across four fictional NHS-style hospitals, focusing on inpatient capacity, outpatient appointments, workforce expenditure, operating costs and discharge delays.

The analysis brings together data from several hospital operational systems to investigate how resources are used, how activity changes over time and where potential inefficiencies may exist.

SQL Server was used to organise, validate and transform the data into analytical views. These views were connected to Power BI, where a relational data model and DAX measures were developed to support performance reporting.

The final report consists of five interactive dashboard pages covering executive performance, admissions and bed capacity, outpatient services, workforce and financial efficiency, and discharge delays.

The project aims to demonstrate how operational data can be transformed into meaningful performance indicators and used to support evidence-based decisions about hospital capacity, service delivery and resource allocation.

**Note:** This project uses synthetic data created for analytical purposes. The hospitals, operational figures and findings do not represent actual NHS organisations or their performance.
